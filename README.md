# Shaan Photography

Premium frontend-only photography portfolio for **Shaan Photography**.

## Stack

- Vite + React 19 + TypeScript
- React Router
- Tailwind CSS v4
- Framer Motion
- react-helmet-async

## Getting started

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Customize

- Contact / social links: `src/config/site.ts`
- Gallery images: `src/data/galleryData.ts`
- Services: `src/data/servicesData.ts`
- Logo: `src/assets/logos/shaan-logo.jpg`

Forms validate on the client and show a local success state only — no backend.
